# Problem Statement

Project teams record risks and issues in emails, Excel sheets and meetings.
This makes tracking slow and inconsistent, and lessons from past projects
are forgotten.

# Proposed Solution

AI Risk & Issue Management Assistant. The user types a risk or issue in
simple language. The AI then:
- Classifies it as a risk or an issue
- Rates its severity and probability
- Suggests mitigation actions
- Finds similar past risks using a vector database (RAG)

# Target Users

Project managers and team leads.

# Project Type

Chatbot with recommender
